# ТЗ: простое приложение для просмотра ТВ на Android TV

## 1. Цель

Разработать максимально простое и лёгкое приложение для **Android TV**,
предназначенное для просмотра обычных телеканалов с пульта.

Основной сценарий:

> Включил телевизор → открыл приложение → сразу запустился последний телеканал →
> стрелками вверх/вниз переключаются каналы → `OK` открывает список каналов.

Приложение не должно содержать фильмы, сериалы, рекомендации, подписки, рекламу
и другие лишние разделы.

Основной приоритет --- простота использования пожилым человеком.

---

## 2. Референс

В качестве референса по интерфейсу, работе с Android TV, D-pad и воспроизведению
можно использовать проект:

**StreamVault-IPTV:**\
https://github.com/Davidona/StreamVault-IPTV

Желательно использовать проект именно как референс и реализовать собственное
лёгкое приложение.

---

## 3. Источник телеканалов

По умолчанию приложение должно автоматически загружать M3U/M3U8-плейлист:

```text
https://raw.githubusercontent.com/Free-TV/IPTV/master/playlists/playlist_russia.m3u8
```

Пользователю не нужно самостоятельно добавлять плейлист при первом запуске.

### Обновление

Плейлист автоматически обновляется:

- при запуске приложения;
- после пробуждения Android TV;
- периодически во время работы, например раз в 6 часов.

Обновление должно происходить в фоне и не мешать просмотру.

Необходимо хранить локальную копию последнего успешно загруженного плейлиста.

Если GitHub или интернет временно недоступен:

- не удалять существующие каналы;
- использовать последнюю сохранённую копию;
- повторить обновление позднее.

---

## 4. Первый запуск

При первом запуске приложение:

1.  автоматически загружает стандартный M3U-плейлист;
2.  парсит список каналов;
3.  сохраняет его локально;
4.  запускает первый доступный канал на весь экран.

Не показывать пользователю экран добавления провайдера, M3U, Xtream Codes и т.
п.

---

## 5. Последующие запуски

При каждом последующем запуске:

```text
Запуск приложения
       ↓
загрузка сохранённых настроек
       ↓
обновление M3U в фоне
       ↓
запуск последнего просмотренного канала
       ↓
полноэкранное воспроизведение
```

Главного меню при запуске быть не должно.

Если последний канал исчез из плейлиста, открыть первый доступный канал.

---

## 6. Управление пультом

Во время полноэкранного просмотра:

Кнопка Действие

---

`↑` Следующий канал `↓` Предыдущий канал `OK` Открыть список каналов `BACK`
Закрыть открытое меню / выход `CH+` Следующий канал, если кнопка присутствует
`CH-` Предыдущий канал, если кнопка присутствует `VOL+` Обычное увеличение
громкости Android TV `VOL-` Обычное уменьшение громкости Android TV

Приложение **не должно перехватывать кнопки громкости**.

Если пульт имеет цифровые кнопки, желательно поддержать прямой ввод номера
канала.

Например:

```text
1 → канал №1
2 → канал №2
5 → канал №5
```

---

## 7. Запрет паузы для Live TV

Это обязательное требование.

Нажатие `OK` **не должно ставить прямой эфир на паузу**.

Для Live TV не нужны:

- Pause;
- Play/Pause;
- timeshift;
- локальная перемотка;
- продолжение просмотра со старой позиции.

`OK` всегда открывает список телеканалов.

Прямой эфир всегда должен воспроизводиться с актуальной LIVE-позиции.

---

## 8. Список каналов

При нажатии `OK` поверх текущего видео открывается простой список.

Пример:

```text
★ Любимые

1   Первый канал
2   Россия 1
3   Матч ТВ
4   НТВ
5   Пятый канал
6   Россия К
7   Россия 24
...
```

Текущий канал при открытии списка продолжает воспроизводиться.

Текущий выбранный канал должен быть хорошо выделен.

Текст должен быть крупным и хорошо читаемым с расстояния.

---

## 9. Любимые каналы

Необходимо реализовать отдельный список **«Любимые»**.

Добавление канала:

```text
долгое нажатие OK
        ↓
Добавить в любимые
```

Повторное действие позволяет удалить канал из любимых.

Можно дополнительно показывать значок:

```text
★
```

### Режим «Только любимые»

В настройках:

```text
Переключение каналов:

○ Все каналы
● Только любимые
```

Если выбрано **«Только любимые»**, кнопки `↑`, `↓`, `CH+`, `CH-` переключают
исключительно любимые каналы.

Это должен быть основной удобный режим для пожилого пользователя.

---

## 10. Изменение порядка любимых каналов

Пользователь должен иметь возможность самостоятельно изменить порядок любимых
каналов.

Например:

```text
1   Первый канал
2   Россия 1
3   НТВ
4   Россия 24
```

В меню управления:

```text
Переместить канал
```

После выбора канал перемещается стрелками `↑/↓`, подтверждение --- `OK`.

Изменённый порядок хранится локально.

Обновление M3U **не должно сбрасывать порядок любимых каналов**.

Для сопоставления каналов желательно использовать стабильный `tvg-id`, а при его
отсутствии --- нормализованное название канала.

---

## 11. Информация при переключении

При переключении канала на 2--3 секунды показывать крупный OSD:

```text
2

РОССИЯ 1

Вести
```

Минимально:

- номер;
- название;
- логотип, если имеется.

Если подключён EPG:

- текущая передача;
- следующая передача.

После нескольких секунд информация автоматически исчезает.

---

## 12. Поведение при выключении телевизора

Это одно из основных требований.

Если пользователь выключает Android TV кнопкой `Power` или устройство переходит
в standby/sleep:

1.  сохранить текущий канал;
2.  не сохранять позицию видео;
3.  не ставить канал на пользовательскую паузу;
4.  корректно освободить/приостановить ресурсы плеера в соответствии с lifecycle
    Android TV.

После включения/пробуждения телевизора:

```text
Android TV проснулся
       ↓
приложение возвращается
       ↓
восстанавливается последний канал
       ↓
выполняется новое подключение к потоку
       ↓
воспроизведение начинается с LIVE
```

Например:

Телевизор выключили в 12:00 и включили в 14:00.

Приложение должно показать эфир **14:00**, а не пытаться продолжить видео с
момента 12:00.

---

## 13. Автовоспроизведение

Настройка:

```text
Автоматически запускать последний канал [ВКЛ]
```

По умолчанию включена.

При открытии приложения не должно требоваться нажимать `Play`, `OK` или выбирать
канал вручную.

---

## 14. Автозапуск после полной загрузки Android TV

Желательная функция:

```text
Автозапуск после включения Android TV [ВКЛ/ВЫКЛ]
```

При поддержке конкретной версии Android TV использовать системно допустимый
механизм автозапуска после `BOOT_COMPLETED`.

Необходимо учитывать ограничения современных версий Android/Android TV: если ОС
или производитель запрещает автоматический запуск Activity после загрузки,
приложение не должно использовать небезопасные обходы.

---

## 15. Обработка буферизации

Не допускать бесконечной надписи `Buffering`.

Пример алгоритма:

```text
Открытие канала
       ↓
подключение
       ↓
таймаут
       ↓
повторное подключение
       ↓
если поток не работает
       ↓
"Канал временно недоступен"
```

Настройка:

```text
Автоматически пропускать недоступные каналы [ВКЛ]
```

Если включено:

```text
канал не работает
       ↓
повторная попытка
       ↓
не работает
       ↓
следующий доступный канал
```

Количество попыток и таймаут не должны приводить к длительному зависанию
интерфейса.

---

## 16. Настройки

Настройки не должны мешать обычному просмотру.

Попасть в них можно, например:

- через пункт `⚙ Настройки` в конце списка каналов;
- либо долгим нажатием `BACK`.

### Раздел «Каналы»

```text
Источник плейлиста
Обновить сейчас
Дата последнего успешного обновления

Переключать:
○ Все каналы
● Только любимые
```

URL стандартного плейлиста можно изменить вручную в расширенных настройках.

### Раздел «Любимые»

```text
Изменить порядок
Удалить канал
Очистить любимые
```

### Раздел «Запуск»

```text
Автоматически запускать последний канал [ВКЛ]

Автозапуск после загрузки Android TV [ВКЛ/ВЫКЛ]
```

### Раздел «Воспроизведение»

```text
Автоматически пропускать неработающие каналы [ВКЛ]

Таймаут подключения:
5 / 10 / 15 секунд
```

### Раздел «Интерфейс»

```text
Размер текста:
○ Обычный
● Большой
○ Очень большой

Показывать логотипы [ВКЛ]
Показывать номера каналов [ВКЛ]
```

### Раздел «О приложении»

```text
Версия
Проверить обновления
```

В настройках:

```text
Проверить обновления
```

Также можно проверять наличие новой версии автоматически, например раз в сутки,
без навязчивых уведомлений во время просмотра.

## 18. EPG

EPG не является обязательным для первой версии, но архитектура должна позволять
добавить его позднее.

При наличии EPG показывать:

```text
Россия 1

Сейчас:
Вести

Далее:
60 минут
```

Отсутствие EPG не должно мешать просмотру телеканала.

---

## 19. Кэш

Локально необходимо сохранять:

- последний успешно загруженный M3U;
- последний просмотренный канал;
- любимые каналы;
- пользовательский порядок любимых;
- выбранный режим `Все / Только любимые`;
- настройки приложения;
- дату последнего обновления плейлиста.

После перезагрузки телевизора настройки не должны пропадать.

Приложение должно быть максимально лёгким.

Не нужны:

- фильмы;

- аккаунты;
- регистрация;

## 23. Главный пользовательский сценарий

Приложение должно ощущаться как обычный телевизор:

```text
Включил телевизор
        ↓
открыл TV
        ↓
СРАЗУ ИДЁТ КАНАЛ
        ↓
↑ / ↓ — переключение
        ↓
OK — список каналов
```

Никаких дополнительных действий для начала просмотра.

Если включён режим **«Только любимые»**:

```text
↑
Первый канал

↑
Россия 1

↑
НТВ

↑
Россия 24
```

И больше никаких ненужных каналов при обычном переключении.

## 24. Критерии готовности

Приложение считается готовым, если выполняются следующие основные условия:

1.  После установки не требуется вручную вводить стандартный M3U URL.
2.  При запуске сразу начинается воспроизведение телеканала.
3.  Последний просмотренный канал восстанавливается.
4.  После sleep/standby канал возобновляется с актуального LIVE-эфира.
5.  `↑/↓` переключают каналы.
6.  `OK` открывает список и **никогда не ставит Live TV на паузу**.
7.  `VOL+/VOL-` продолжают управлять системной громкостью.
8.  Можно добавлять каналы в любимые.
9.  Можно включить режим переключения только между любимыми.
10. Можно менять порядок любимых каналов.
11. M3U автоматически обновляется без потери пользовательских настроек.
12. При недоступности GitHub используется сохранённый плейлист.
13. Неработающий канал не приводит к бесконечной буферизации.
14. Всё приложение полностью управляется обычным D-pad пультом Android TV.
15. Интерфейс пригоден для использования человеком с плохим зрением.
