# ZTV

## Плейлист

Приложение загружает `playlist.m3u8` из этого репозитория при запуске и повторяет
проверку каждые 15 минут. Состав, порядок и адреса каналов меняются прямо в этом файле.

## Автоматическое восстановление каналов

GitHub Actions `Repair playlist` запускается каждый час на 17-й минуте, при изменении
плейлиста или вручную через вкладку Actions. Компьютер владельца для этого не нужен.
Проверка расписания может задерживаться на стороне GitHub.

Для ваших 20 каналов используются резервные адреса из `playlist-sources.json` и
актуальных списков `iptv-org/iptv` и `Free-TV/IPTV`. Резервы сопоставляются по точному
`tvg-id` и разрешённому адресу источника для этого канала; зарубежные и сдвинутые
по времени версии отбрасываются. Новые неизвестные домены автоматически не допускаются.
Рабочая ссылка остаётся на месте. После двух неудачных проверок скрипт ищет замену,
проверяет живой HLS, видео H.264 до 720p и звук AAC, декодирует видеофрагмент и повторно
проверяет, что эфир продолжает обновляться. Только после этого URL меняется в `playlist.m3u8`.
Названия, порядок, идентификаторы и избранное сохраняются. APK обновлять не нужно.

Ответы 403/451 считаются возможной геоблокировкой, а не доказательством поломки.
При массовой недоступности или отсутствии проверенного резерва старая ссылка
сохраняется; чужой канал не подставляется. За один запуск заменяются максимум три
адреса. Это не гарантирует эфир при отключении всех источников или блокировке сети
конкретного телевизора. Текущее состояние опубликовано в `playlist-health.json`,
подробности каждой проверки доступны в Actions и его артефакте `verified-playlist`.
Ежедневное обновление отчёта также поддерживает активность расписания репозитория.

Ручная проверка без публикации:

```bash
python -m pip install --require-hashes --only-binary=:all: -r scripts/requirements.txt
python -m unittest discover -s scripts -p 'test_*.py' -v
python scripts/repair_playlist.py --output .Codex/playlist-repair
```

Для проверки нужны Python 3.11 или новее, `ffprobe` и `ffmpeg` в `PATH`. В GitHub Actions они
устанавливаются автоматически. Скрипт формирует результат в указанном каталоге;
этап публикации сверяет контрольные суммы плейлиста и правил проверки, чтобы не
затереть ручную правку или применить устаревшие правила. Проверка каждого канала
ограничена тремя минутами; один зависший сервер не блокирует весь список.

Лёгкое Android TV приложение для просмотра live-телеканалов с D-pad пульта.

## Что уже есть

- автозагрузка стандартного M3U/M3U8 плейлиста;
- локальный кэш последнего успешного плейлиста;
- fullscreen Media3/ExoPlayer без стандартных play/pause контролов;
- `OK` открывает список каналов и не ставит live-эфир на паузу;
- `←` открывает настройки, `→` закрывает текущее меню;
- `↑/↓` и `CH+/CH-` переключают каналы;
- цифровой ввод номера канала;
- OSD при переключении;
- озвучивание названия выбранного канала через системный Android Text-to-Speech;
- избранные каналы и режим переключения только по избранным;
- изменение порядка любимых каналов с подтверждением через `OK`;
- поддержка актуальных потоков «Россия 1», «Россия 24» и «Россия К» из старых ссылок плейлиста;
- локальные настройки через DataStore;
- reconnect после sleep/standby с новой live-позицией;
- включённый по умолчанию boot receiver с отложенным системным fallback-запуском;
- автоматическое восстановление последнего канала после включения Android TV.

## Надёжный автозапуск

Google TV и некоторые Android TV блокируют обычный запуск приложения по событию загрузки. После установки ZTV 0.1.11:

1. Откройте ZTV и нажмите `←`.
2. Выберите `Системное разрешение автозапуска: ВЫКЛ` и разрешите ZTV показываться поверх других приложений.
3. Убедитесь, что пункт изменился на `Системное разрешение автозапуска: ВКЛ`.
4. Выберите `Проверить автозапуск сейчас`: откроется главный экран, а через пять секунд ZTV должна вернуться.
5. Дополнительно выберите `Надёжный автозапуск: открыть Специальные возможности` и включите `ZTV Автозапуск`.
6. Оставьте обычный пункт `Автозапуск после загрузки Android TV` включённым.

ZTV не рисует плавающие окна: системное разрешение используется только как разрешённое Android исключение для открытия приложения из фона. Служба работает только в первые десять минут после загрузки телевизора, не читает содержимое экрана и не обрабатывает нажатия. Она не обращается к пользовательскому хранилищу во время загрузки и повторяет запуск после завершения старта главного экрана телевизора.

Если файл DataStore повреждён после аварийного отключения питания, ZTV автоматически заменяет его чистыми настройками вместо повторяющегося падения приложения.

На телевизорах, где синтезатор речи долго запускается после включения, ZTV повторно подключается к нему и произносит название канала после готовности русского голоса.

Если Android 13 или новее не позволяет включить службу, откройте `Настройки → Приложения → ZTV`, выберите меню `⋮`, нажмите `Разрешить ограниченные настройки`, затем повторите шаги выше.

## Сборка

Нужен установленный Android SDK. Укажите путь одним из способов:

```properties
# local.properties
sdk.dir=C\:\\Users\\ZZII\\AppData\\Local\\Android\\Sdk
```

или задайте переменную окружения `ANDROID_HOME`.

После этого:

```powershell
$env:JAVA_HOME='C:\Program Files\Microsoft\jdk-21.0.11.10-hotspot'
.\gradlew.bat assembleDebug
```
