# ZTV

## Плейлист

Приложение загружает `playlist.m3u8` из этого репозитория при запуске и повторяет
проверку каждые 15 минут. Состав, порядок и адреса каналов меняются прямо в этом файле.

Лёгкое Android TV приложение для просмотра live-телеканалов с D-pad пульта.

## Что уже есть

- автозагрузка стандартного M3U/M3U8 плейлиста;
- локальный кэш последнего успешного плейлиста;
- fullscreen Media3/ExoPlayer без стандартных play/pause контролов;
- `OK` открывает список каналов и не ставит live-эфир на паузу;
- `←` открывает настройки, `→` закрывает текущее меню;
- `↑/↓` и `CH+/CH-` переключают каналы;
- цифровой ввод номера канала;
- OSD при переключении;
- озвучивание названия выбранного канала через системный Android Text-to-Speech;
- избранные каналы и режим переключения только по избранным;
- изменение порядка любимых каналов с подтверждением через `OK`;
- поддержка актуальных потоков «Россия 1», «Россия 24» и «Россия К» из старых ссылок плейлиста;
- локальные настройки через DataStore;
- reconnect после sleep/standby с новой live-позицией;
- включённый по умолчанию boot receiver с отложенным системным fallback-запуском;
- автоматическое восстановление последнего канала после включения Android TV.

## Надёжный автозапуск

Google TV и некоторые Android TV блокируют обычный запуск приложения по событию загрузки. После установки ZTV 0.1.7:

1. Откройте ZTV и нажмите `←`.
2. Выберите `Надёжный автозапуск: открыть Специальные возможности`.
3. В системном меню включите службу `ZTV Автозапуск`.
4. Оставьте обычный пункт `Автозапуск после загрузки Android TV` включённым.

Служба работает только в первые десять минут после загрузки телевизора, не читает содержимое экрана и не обрабатывает нажатия.

Если Android 13 или новее не позволяет включить службу, откройте `Настройки → Приложения → ZTV`, выберите меню `⋮`, нажмите `Разрешить ограниченные настройки`, затем повторите шаги выше.

## Сборка

Нужен установленный Android SDK. Укажите путь одним из способов:

```properties
# local.properties
sdk.dir=C\:\\Users\\ZZII\\AppData\\Local\\Android\\Sdk
```

или задайте переменную окружения `ANDROID_HOME`.

После этого:

```powershell
$env:JAVA_HOME='C:\Program Files\Microsoft\jdk-21.0.11.10-hotspot'
.\gradlew.bat assembleDebug
```
